Before you start

You are about to work on a software project in an online code editor, as part of an interview. While you work, your activity here is recorded and shared with the interviewer. Please read what that means.

What is recorded

  • Which file you have open, and which line your cursor is on.
  • When you save a file, and how many lines it has.
  • How many lines you type yourself.
  • The programming language, the project and branch you are working on, and the time of each event.
  • The names of the libraries a file imports. These are sent with each event but not kept.

What is not recorded

Your screen, your keystrokes, what you type in the terminal, what you search for, and the contents of your files are not part of this activity record. The files you create and change here do stay in this environment, and the people running the interview can see them.

The internet

This environment can only reach the sites needed to download the project and its packages. Other sites are blocked from here.

Who sees it

The interviewer receives a report built from this record. How long it is kept, and who else can see it, is set by the company running this interview. Ask them if you want to know before you continue.

Your choice

If you do not agree, close this page and tell the interviewer. Nothing is recorded until you continue.
